# 便签 Sticky Notes

一个独立的桌面便签应用，使用 Rust + GPUI 编写。便签保存在应用自己的 SQLite 数据库里，可以一键导入 Windows 便签的内容，并通过 WebDAV 在多台设备间同步。

> 🚧 **项目正在持续开发中**，功能、界面和数据结构都可能随时调整。

## 功能

- 独立的 SQLite 数据库（`stickynotes.db`）：便签正文以 Markdown 原样保存，标题、代码块、表格、任务列表都不会丢失
- 数据库位置可在设置中查看和更改
- 从 Windows 便签导入（只读，不会改动系统便签）
- 标签分类、置顶、全文搜索
- 7 种便签纸主题
- Markdown 编辑器：标题与正文分离、图标格式工具条
- 粘贴图片：截图、浏览器里复制的图片、资源管理器里复制的图片文件都能直接 `Ctrl+V` 贴进便签，图片存在便签正文里，跟着便签一起备份和同步（见下文「粘贴图片」）
- WebDAV 同步：每条便签保存为 `<id>.md`（YAML Frontmatter + Markdown 正文），默认开启自动同步，删除也会传播到远端
- 自动备份：定期保存数据库快照
- 托盘与快速记事：关闭窗口后可留在托盘；左键点托盘图标打开快速记事，右键弹出菜单（打开主面板 / 快速记事 / 设置 / 退出便签）
- 全局快捷键：便签运行时，在任何程序里按 `Ctrl+Alt+Q` 打开快速记事、按 `Ctrl+Alt+S` 打开主面板，可在「设置 › 快捷键」里修改或清除
- 开机自启动（设置 › 通用）：登录 Windows 后自动启动；「关闭窗口时」设为「留在托盘」时直接待在托盘，不弹出窗口

## 数据存储

所有便签、标签和置顶状态都在一个文件里：`stickynotes.db`。

- **默认位置**：`%LOCALAPPDATA%\stickynotes\stickynotes.db`。
- **查看 / 更改位置**：侧边栏底部的齿轮按钮打开设置，「便签数据库」一栏显示完整路径。
  - **更改位置…**：选择一个文件夹，数据库会被移动过去（先完整复制并校验，成功后才删除旧文件）。
  - 如果所选文件夹里已经有 `stickynotes.db`，应用不会覆盖它，而是询问是否改用那个数据库；原来的数据库留在原处。
  - **恢复默认**：把数据库移回默认位置。
  - **打开文件夹**：在资源管理器中定位数据库文件。
- 如果启动时数据库打不开（例如所在的移动硬盘没有连接），应用只显示一个恢复界面：可以重试，或改用默认位置，不会悄悄换成一个空数据库。
- **备份**：应用运行期间每隔约 4 小时在 `%LOCALAPPDATA%\stickynotes\backups\` 保存一份完整快照（`notes-<时间>.db`），保留最近 30 份。备份始终放在这个目录，不随数据库位置移动。

> 不要把数据库放进网盘的同步目录、再让多台设备同时打开它——SQLite 文件不适合这样共享。多设备同步请使用下面的 WebDAV。

### 从 Windows 便签迁移 / 导入

早期版本直接读写 Windows 便签的 `plum.sqlite`。现在应用只把它当作导入来源，**只读、从不写入**：

- **首次启动自动迁移**：把 Windows 便签里的全部便签（保留原有的 ID、颜色和时间）以及旧版本保存的 Markdown 格式、标签、置顶一起迁入 `stickynotes.db`。便签 ID 和修改时间不变，所以 WebDAV 上的文件不需要重新上传。每台电脑只自动迁移一次。
- **之后手动导入**：设置里的「导入 Windows 便签」按便签逐条合并——新便签会被加入；在 Windows 便签里改过、且比这里更新的便签会被更新；在这里编辑或删除过的便签不受影响。导入不会删除任何便签。
- Windows 便签只保存纯文本（外加粗体、斜体和列表），所以从那里更新过来的便签不含标题、代码块等 Markdown 格式。
- 迁移后旧文件 `%LOCALAPPDATA%\stickynotes\markdown.sqlite` 和 `tags.db` 不再使用，确认一切正常后可以手动删除。`backups\` 里按时间命名的子文件夹是旧版本对 `plum.sqlite` 的备份，同样不再更新。

## 粘贴图片

在便签里按 `Ctrl+V` 就能插入图片，主面板和快速记事都可以：

- **能粘贴什么**：截图（截图工具、PrintScreen 等放进剪贴板的位图）、浏览器里「复制图片」得到的图片、在资源管理器里复制的图片文件（png、jpg、jpeg、jfif、gif、webp、bmp、dib、tif、tiff）。一次最多 10 张，每张单独占一行。
- **存在哪里**：图片以内嵌图片的形式写进便签的 Markdown 正文（`![图片](data:image/png;base64,…)`），和文字一起存进 `stickynotes.db`，随自动备份和 WebDAV 同步，不另建附件目录。
- **自动压缩**：长边超过 1920 像素的图片按比例缩小；不超过 1 MB、尺寸也合适的 PNG、JPEG、GIF、WebP 原样保存；其余的转成 PNG，不透明的大图如果存成 JPEG 能小一半以上，就改存 JPEG。压缩后仍超过 6 MB 的图片不插入，状态栏会说明原因。压缩在后台进行，不会卡住输入；主面板压缩时左下角显示「正在插入图片…」。
- 剪贴板里同时有文字和图片时，贴入的是文字（Excel、Word 复制内容时会顺带放一张图片）。`Ctrl+Shift+V` 只粘贴纯文本。代码块里不能插入图片。
- 图片不参与搜索、列表摘要和字数统计。便签第一行是图片时，这条便签没有标题，图片留在正文里。
- 把含图片的内容复制到其他程序，图片处显示文字「图片」；复制后贴回便签，图片完整保留。
- 图片会让便签和 WebDAV 上的 `.md` 文件变大（base64 编码比图片本身大约三分之一）。多台设备同步时，请都升级到 0.6.0 或更新的版本：旧版本上传一条第一行是图片的便签时，可能把这张图片丢掉。

## WebDAV 同步

设置中的同步部分：

- **自动同步（WebDAV）**：默认开启；关闭后只在点「立即同步」时同步，下面的「编辑后上传延迟」随之变灰、不可修改。编辑后约 2.5 秒上传；启动时立即检查一次，回到窗口时（30 秒内最多一次）以及后台静默轮询（窗口可见时每 5 分钟、藏在托盘时每 10 分钟）做一次轻量检查（一条 PROPFIND，按 ETag / Last-Modified 判断，只下载有变化的文件）。这个后台间隔只用于拉取其他设备的改动，不影响本机编辑后的上传速度。颜色、标签、置顶的修改也会单独同步，且不会改变便签在列表中的位置。冲突按整条便签的版本（文字时间与颜色/标签/置顶时间取较新者）最新者胜出。删除是双向传播的：本机删除的便签会在下一次同步移除远端文件；远端被删除的文件（且本机没有更新过）也会在本机随之删除。后台检查没有变化时不打扰状态栏；失败会立刻在状态栏和侧栏圆点提示，并指数退避重试（30 秒起，最长 10 分钟），恢复后自动转绿。侧栏的同步状态会明确区分：进行中显示旋转图标（后台检查显示「正在检查更新…」），用户触发的同步完成后短暂显示「同步完成 · N 项更新」，平时显示「自动同步已开启」或「自动同步已关闭」；未填写服务器时显示「本地存储」。左下角始终有这一行状态提示。未填写服务器地址时静默跳过。
- 表单：服务器地址、用户名、密码（可切换显示）、远端目录（默认 `/StickyNotes/`，不存在时自动 MKCOL 创建）、代理（可选，支持 `http://` 与 `socks5://`，留空则直连）。
- **测试连接**：非空校验 + Basic Auth 的 `PROPFIND` 请求，内联显示结果；网络错误会带上底层原因（DNS、连接超时、TLS 等）。
- 同步客户端不读取 Windows 系统代理设置（只认 `HTTP_PROXY` 等环境变量），需要走代理时请在「代理」框里填写，例如 `http://127.0.0.1:7890`。

配置保存在 `%LOCALAPPDATA%\stickynotes\config.json`（密码为明文存储，建议使用应用专用密码）。远端文件版本缓存保存在同目录的 `webdav-cache.json`，待传播的本地删除记录在 `webdav-deletions.json`（两者只含文件名、ETag 和时间戳，不含便签内容）。删除 `webdav-cache.json` 后下次同步会重新比对全部文件。远端文件可直接用任意 Markdown 编辑器打开。

远端文件开头的 YAML Frontmatter（`---` 包围的元数据块）用于记录 `id`、颜色、标签、置顶和修改时间，是同步冲突判断的依据。Obsidian、VS Code、GitHub、Typora 等会在预览中自动隐藏它；如果你的查看器不支持 Frontmatter，元数据会作为普通文本显示，此时请用上述编辑器打开或查看原始文本——便签正文本身不受影响。

## 运行

```bash
cargo run -p stickynotes-app
```

发布版：在仓库根目录执行 `build-release.cmd`，编译 release 并把 `target\release\stickynotes.exe` 复制一份到仓库根目录，`cargo clean` 不会删掉这份副本。

需要 Rust 工具链，支持 Windows 10 / 11。不需要安装 Windows 便签。

开发时可以先演练一次迁移（只读取现有数据，写入临时数据库后即删除，只输出数量，不输出便签内容）：

```bash
cargo run -p stickynotes-core --example migrate_check
```

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `crates/app` | 桌面 UI（GPUI） |
| `crates/core` | 便签数据库、Windows 便签导入、备份、WebDAV 同步 |
| `crates/vendor/markdown-editor` | Markdown 编辑器组件 |

## 说明

- 便签内容属于个人隐私：`target/`、`backups/`、截图、日志和编译产物均已在 `.gitignore` 中排除，不会进入仓库，也不影响正常推送。
- 应用不会修改 Windows 便签的数据库。
